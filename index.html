Quit Synklok

Pro Tools jumps from 48 to 96 kHz. Your MADIface follows. Your M-1620 doesn't.

Now you've got dropouts, clicks, or audio at the wrong pitch — until you click through the web UI or the rack unit's front panel.

Synklok closes the loop. When the MADI input rate changes, it tells the M-1620 to match — within two seconds. You don't have to think about it.

Built to disappear

Three things matter. Synklok does them well, and nothing else.

Set and forget

Runs quietly in the menu bar. Launches at login. Updates itself. Once installed, you never have to think about it again.

Glance-able status

Connection state, current rate, MADI sync, and recent changes — all visible in one click. Or put the rate right in the menu bar.

Built for pro audio

Native macOS app. Open source. No analytics. No accounts. Talks directly to the M-1620's REST API — the only other thing it contacts is synklok.app, once a day, to check for updates.

Install

Two minutes, once. After that Synklok checks for new versions daily and installs them in one click.

  1. 1
    Download Synklok
    Download the DMG. It's signed and notarized by Apple. Use a browser, email, or AirDrop to pass it on — not WhatsApp, which marks files so macOS refuses to open them.
  2. 2
    Drag it to Applications
    Open the DMG and drag Synklok onto the Applications folder.
  3. 3
    Open it
    Launch Synklok from Applications and click Open when macOS asks about an app downloaded from the Internet.
  4. 4
    Allow local network access
    Click Allow when Synklok asks to find devices on your local network — it needs this to reach the M-1620. Missed it? System Settings → Privacy & Security → Local Network.
  5. 5
    Find the metronome
    Synklok lives in the menu bar, not the Dock. Click the metronome for status, and turn on Launch at login.

Coming from the old “M-1620 Rate Sync” script?

Remove it first — it also changes the sample rate and will fight Synklok. Synklok warns you if it finds it. Paste this into Terminal; it asks for your Mac password. 

launchctl unload ~/Library/LaunchAgents/com.studio.m1620sync.plist 2>/dev/null; rm -f ~/Library/LaunchAgents/com.studio.m1620sync.plist; sudo launchctl unload /Library/LaunchDaemons/com.studio.m1620sync.plist 2>/dev/null; sudo rm -f /Library/LaunchDaemons/com.studio.m1620sync.plist /usr/local/bin/studio/m1620_rate_sync.py; sudo rmdir /usr/local/bin/studio 2>/dev/null; sudo pkgutil --forget com.studio.m1620sync >/dev/null 2>&1; rm -f /tmp/m1620_rate_sync.log; echo "Old M-1620 Rate Sync removed"

Compatibility

macOS
Available
  • macOS 14 Sonoma or newer
  • Apple Silicon & Intel — universal binary
  • Follows the M-1620's coaxial MADI input (optical MADI and word clock are on the roadmap)
Windows
Coming soon

A native Windows 10 / 11 build is on the roadmap. The core sync logic is the same — only the menu-bar/UI layer needs porting. Star the GitHub repo to be notified when it lands.

Both versions require the RME M-1620 Pro D connected via USB REMOTE or on the same LAN.
